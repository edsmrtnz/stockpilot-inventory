# StockPilot Inventory

A responsive inventory, ordering, and sales-management demo built for my developer and IT portfolio.

## Features

- Dashboard with inventory and sales metrics
- Product search, filtering, add, edit, delete, and stock adjustment
- Recent order tracking
- Responsive mobile layout
- Philippine peso currency formatting
- Local browser persistence for demo data

## Tech stack

React, TypeScript, Tailwind CSS, Lucide React, and vinext.

## Live demo

https://stockpilot-inventory-demo.edsmartiinez.chatgpt.site

## Run locally

```bash
npm install
npm run dev
```
